# «Как происходит донация?» — Центр крови О.К. Гаврилова

Одна вертикальная страница из четырёх секций: главный экран → шаг 1 → шаг 2 → шаг 3.
Свёрстана по четырём скриншотам-эталонам шириной 1750 px и масштабируется под ширину окна целиком, без перестановки слоёв.

## Запуск

```bash
cd donation-page
python3 -m http.server 8000
# http://localhost:8000/            — обычный режим, ручной скролл
# http://localhost:8000/?demo=1     — автодемонстрация (0:00–0:19), останавливается при любом действии пользователя
# http://localhost:8000/?still=1    — нейтральная фаза без микродвижений (для сверки со скриншотами)
```

Страницу нужно открывать через локальный сервер: по `file://` браузер не даёт WebGL читать картинки, и персонажи показываются статично, без деформации.
Демонстрацию можно запустить и из консоли: `startDemo()`, остановить — `stopDemo()`.

## Устройство

Всё лежит в `index.html` (чистые HTML/CSS/JS, без сборки):

- `HERO`, `STEPS` — конфигурация: координаты слоёв, тексты, параметры микродвижений;
- `Header`, `Hero`, `StepSection`, `Character` — компоненты;
- `Character` рисует исходную иллюстрацию через WebGL и слегка деформирует её локальными «ручками»
  (голова, кисти, лист, дыхание). Рисунок не перерисовывается: в нейтральной фазе смещение равно нулю;
- `DEMO` — сценарий автопрокрутки;
- `prefers-reduced-motion: reduce` отключает микродвижения, появление секций и демо.

## Ассеты

`assets/` — слои, аккуратно извлечённые из присланных скриншотов (оригинальных исходников не было):

| Файл | Что это |
|---|---|
| `logo.png` | логотип (птица + подпись) |
| `cell-A…D.png` | четыре эритроцита отдельными слоями; под заголовком и в местах перекрытий клетки достроены |
| `step1…3-char.png` | персонажи с прозрачным фоном |
| `step1…3-blob.png` | цветные органические плашки (текст и цифры из них убраны) |

Овальные контуры и наклонная линия нарисованы в SVG по замерам со скриншотов.

**Для идеальной точности нужны оригиналы:** логотип в SVG, эритроциты и персонажи в PNG/WebP с прозрачностью
(у персонажей лучше разложить на части: голова, руки, лист, ручка), плашки в SVG или PNG.
Файлы с теми же именами заменяются в `assets/` без правки кода.

## Шрифты

`fonts/` — локальные копии Google Fonts (OFL): Montserrat 500/800, Belanosima 400.
Заголовок главного экрана на скриншоте набран альтернативными глифами Montserrat (д, т, и как g, m, u) —
это Montserrat Alternates ExtraBold 800, он тоже подключён. Если нужен строго обычный Montserrat ExtraBold,
замените `font-family` у `.hero-title`.
