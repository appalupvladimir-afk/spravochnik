# Центр крови О.К. Гаврилова — анимация экрана «Как происходит донация?»

- `index.html` — страница: открывается в браузере, анимация запускается сама, без кликов (≈10,6 с, без повтора).
- `blood-center-animation.mp4` — готовая запись (H.264, 60 FPS, 2156×1574, без звука).
- `record.js` — покадровая запись той же страницы в MP4: `node record.js [out.mp4] [--fps 60] [--scale 2]` (нужны Playwright и ffmpeg).
- `fonts.css`, `fonts/` — локальные Inter, Montserrat, Montserrat Alternates (OFL).

Данные карточек (`CARDS`), четыре состояния (`STATES`) и таймлайн (`T`) лежат в начале скрипта отдельно от логики анимации.
Кадр рисуется функцией `render(t)` от времени, поэтому браузерное воспроизведение и запись совпадают.

| Время, с | Событие |
|---|---|
| 0,3–2,2 | счётчики (жирное начертание) 0 → 120 000 / 3 / 13 000 |
| 3,0–4,1 | 1 + 4 → 2 + 5 |
| 5,1–6,2 | 2 + 5 → 3 + 6 |
| 7,2–8,4 | 3 + 6 → 4 + 7, лента сдвигается влево |
| 8,4–10,6 | финальный кадр |
